Storage
  mac-roster.chr is40960B in existing physical pages668..707. Only668..676
    hold packed body cells;704 preserves the existing original star page
    byte-exact;705/706/707 hold the three portraits. Rest remains zero.
  There are16 genuine/adapted body poses per variant +3 portraits =51 frames.
  Right and left records share CHR, with real Hflip and x'=8-x about player
    center7.5. Maximum9 hardware8x16 parts, header36. No empty padding parts.
  MAC_ROSTER_CORE is reserved95:A310+; MAC_ROSTER_ART94:C2C0+.
    Actual ca65 sizes and projected ends are in build/mac_roster_component.json.
    An unlinked object is not a callable address/whole-game qualification.

State and shared hook interface
  MacVariant=$5FE2,0 Mac /1 Doc Louis /2 Mike Tyson, menu-persistent.
    Select should cycle3 values for char15; shared registry owns selection.
    Invalid stored values render/use baseline Mac safely, without a new flag.
  MacRosterSetPose replaces the semantic LmSetPose call by genuine farcall:
    X=0idle,1/2walk,3duck,4punch,5super,6air,7hurt,8duckpunch,9ducksuper;
   10 is portrait. It sets genuine C94 SmPosePtr, SmChrBank and body sentinel.
    X/Y preserved; final A=old sentinel, C=facing CMP#2; post-palette V/D/I
    retained. It does not write LmPose or other hidden scratch state.
    Caller/full-IRQ equivalence is pending linked integration; no broad mask.
  MacRosterPublish mirrors existing physical-CHR upper2/special704 publication.
    Retain genuine old source DrawGate/star drawing and lifecycle owner.
  MacRosterPortrait: call LmEnsure first, then this portrait entry. It publishes
    actual portrait data and player palette. No full body substituted for Doc.
  MacRosterQueuePalette/ForcePalette use existing LmPalette and original
    six-byte3F11/3 command, guard offset<78, player subpalette0 only. Select
    must invalidate LmPalette so the previous variant's cached colors cannot stick.

    reach24, heights12/42, heartcost2, recovery36. Fast/reaching, more spirit cost.
  These are intentional platform boxing differences, not original opponent AI.
  MacRosterAttackTotal/AttackWindow return genuine age contracts; exported

    remain authoritative. CanAfford must execute before any star debit or
    attack start. SpendHearts subtracts exact1/2 only if enough remain; it does
    not refill anything. Preserve the original +1 hit refund and star cost1.
    Keep original damage/contact/defeat/block/lifecycle mechanisms.
  Poses show windup/active/recovery from the same actual remaining-age windows.
    Source Mac has no crouched uppercut; its actual duck-punch art is reused
    honestly with the existing super volume. No new attack move is invented.
