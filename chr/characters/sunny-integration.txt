This is Super Sunny World, an original homebrew by Matt Hughson with lead
artist Kenneth Fejer: https://mhughson.itch.io/super-sunny-world . It is not
a stock Mario recolor. An early padding-based pirate-ROM comparison was
withdrawn; no meaningful matching code blocks supported that attribution.

The requested port deliberately inherits Mario-family gameplay. It does not
claim to port Sunny's original physics or powers. Small/big/fire are the
host's forms; no new ability is invented. Native Sunny pixels and poses come
from actual ROM records/CHR4,12,24 and the executed source OAM interpreter.
The original 8x8 art is repacked exactly to host 8x16 with +12Y anchor shift.
No pixel scaling/recoloring. Native palette 04/26/36, source alternate-power
palette 04/2A/36 for the inherited Fire tier. Preview RGB is approximate.
Small raw frame9 is hair/debris, not a full body; retained as source data but
not selected as a semantic player pose. Portrait uses the genuine small idle.

Allocations, confirmed against exact canonical85af bytes in asset manifest:
SUNNY_CORE physical81 A-window B200..<C000 (3584B reservation).
SUNNY_ART physical94 C-window CE00..<E000 (4608B reservation; Mac ends CD98).
SUNNY_CHR pages724..739 (16KiB reservation, pages724..727 actually used).
Persistent SunnyForm/Ready/Life/Area/World/Palette/LastForm/Future at5FB8..5FBF.
Active SunnyClock/Pose/Frame/Temp/AnimationStep at5C00..5C04, only selected23.
Area snapshot uses (AreaType<<5)|AreaAddrsLOffset, never the mutable future
destination AreaPointer. Form is restored on selection/area; real life loss
clears it, life gains preserve it. The future byte has no invented power.
