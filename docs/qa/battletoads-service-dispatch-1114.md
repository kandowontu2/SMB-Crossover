## Current bytes and measured work

`audit_battletoads_service_dispatch_1114.py` sessions 31425/68922/34259 bind the
current service table, executed callers and router disassembly. Each idle Main
actually invokes 12 public callbacks, each with one `CfOrBtCheck` and one full
`BtCheck`. It is not six callbacks with duplicate checks. The order is slots
29, 0, 13, 12, 10, four calls to 14, 34, 9, 2. Slots 9 and 29 each execute once
and their private implementation is exactly CLC/RTS at B546. Other unavailable
slots are 3, 18, 20, 21, 22, 23, 27, 31, 33, 35; these are not proposed for new
routing here.

The public 36-entry table is PRG87:B020, followed by the shared router at B08E;
the existing 224-byte envelope ends at B100. Its owner gate admits raw IDs
27/29/31/33. Proposed NoOp admission is explicitly raw33 only. The current
private native head/side wrappers at RAM3:B2D9/B2EB consist solely of a farcall
to the original fixed native query at 9587/958B. These routines do not need
private Battletoads data to calculate vanilla terrain. The native query builds
its own block-buffer pointer and reads the native world; no private callback
is needed on the proposed route.

Current callers are independently bound by their actual recent JSRs: inventory
slot29 PRG86:A5D0, movement0 PRG124:A0E6, box13 A6AF, adder12 A64C, head10 A4D7,
side14 AADF, weapon34 AD72, visible9 A476, draw2 A1A8. The current head and side
dispatch are table-driven; the old retained side `CMP #14` source is not the
current program.
