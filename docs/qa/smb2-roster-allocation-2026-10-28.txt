Explicit authored SMB1-world adaptations PROPOSED, not original SMB2 claims
  Dry movement: retain four original23B stat records, exact action ordering,
  running/carried caps,60-update crouch charge, Luigi native low gravity and
  Peach up-to60-update float. No convenient SMB1 replacement jump. Terrain,
  camera, pipes, enemy contact and carry callbacks are honest host interfaces.
  Health: start native two hearts(1F/max-index0), one-heart small source art;
  real injury loses one heart and uses original hurt/knockback/protection.
  Mushroom: original max-heart increment/full heal, explicitly cap at four
  hearts/index2 because SMB1 can supply more than the two unique subspace
  mushrooms. At cap it heals without indexing past original health table.
  Flower: new crossover reserve of three native vegetables, cap9; no fireball
  or claimed original fire tier. Fresh Down+B on supported solid ground with
  empty hands spends one only on successful allocation, plays native lifting
  delay/art/SFX, and yields a genuine held vegetable. FreshB throws using the
  original four-class carried stats, direction/duck/throw tables and actual
  throw collision. No free repeated empty-hand projectile or acquired HP seeds.
  Carry: one held/two thrown owner records with real actor identity/epoch.
  Adapt only eligible ordinary walking Goomba/Koopa classes initially; never
  plants/firebars/bosses/arbitrary Enemy_State writes. Hard native stand-on-head
  and freshB lift, Easy ordinary stomp unless explicit Down+B grab admission.
  Held/thrown host actors need exact hide/release/contact/death/transition
  lifecycle. Missing eligible classes are disclosed, not silently generalized.
  SMB1 swimming is authored: use native SMB1 water vertical stroke/hazards,
  retain four class horizontal/carried caps, disable dry Peach float only in
  water; return to exact dry integrator on exit. No original SMB2 swim routine
  was found. Do not present this as an authenticated original water engine.
  Native jars/doors/quicksand/climbing require explicit handoffs when host
  terrain supports them; no invented SMB1 equivalents from the isolated audit.

Recommendation
  Approve CORE/ART/CHR and owner-gated RAM independently only if these semantics
  are desired. Audio storage is credible but requires deliberate Roll relocation
  plus two regenerated clones, not an already available blank bank. Keep that
  repack as a named, separately qualified prerequisite. Exact assembled fit,
  full source-vs-port callers, all foreign and IRQ controls, cost, authentic
  complete audio and actual native playability remain future work. ROOT owns
  all shared integration and native launches.
