- Table alias equivalence requires the whole low/high/bank triplet, not just
  the low address. The measured old triplets are identical and new eight
  other records are exact. Original A/X/Y/P are restored before dispatch;
  temporary classifier-X is not a public output.
- The original frontend uses SEC/SBC12. Incoming D1 must be tested with
  RP2A03/NesMPU decimal suppression; generic6502 decimal behavior is the wrong

  proof that arbitrary synthetic P bits are hardware states. Incoming V must

  target/bank/argument setup; the public BT router derives service context

  paths. Row2 must never be replaced by a cache leaf or global Cset bypass.

  eventual BT service. Compare actual public row2 continuation, carry/result,
