# Three-campaign frontend and data loader

The private candidate displays SMB1, SMB2J and All Night Nippon.86 menu identities remain unchanged. A cold controller-only emulator sequence verifies the three screens, a full8KiB original2J data transfer into separate physicalRAM4, return to the selected Peach alternate and normal SMB1 startup/gameplay. All four data profiles also pass the source-linked buffered-PPU decoder/loader checks.

This candidate is not installed. SMB2J and ANN gameplay remain deliberately unavailable: their parsers, additional mechanics, progression, saves and endings still need integration and native checks. The private candidate uses64KiB volatile WRAM; persistent saves are not implemented. It does not claim physical-cartridge compatibility from emulator tests alone.
