## The shared inventory defect

`InventoryHasRaw` and `InventorySpend` pass a requested local item in A into
`InventoryLegacyClassic`. Its expanded mode leaf loads the character/alternate
ID into A. The callers then used that returned character ID as the item index.
For example, Hard Samus with owned mask131 has Morph Ball(item1), but the old
query tested item2 and refused transformation. The same mistake could inspect
the wrong passive upgrade, skip a collected weapon during selection or charge
the wrong ammunition pool.

The existing mode wrapper now calls a six-byte same-bank shim that saves the
requested item, calls the unchanged mode leaf and restores A. Its boolean C
and X/Y behavior remain intact; N/Z now describe the requested A as intended.
The old predicate and all old runtime symbols retain their addresses. The shim
has its own segment after the last existing bank66 segment.

118272 actual linked ownership calls pass independent bit-mask oracles;

modes, powered/unpowered states, all16 item bits, mixed/single-bit ownership,
alternate gates, empty/affordable/free/star cases and untouched other pools.
4740 real linked IRQ injections over120 paths preserve caller state and the
corrected requested A. This is not a timed audio-NMI proof by itself.

Fresh native Hard tests physically collect Morph Ball as Samus and transform

## The thin-block correction

A retained PU Donatello Hard replay exposed a real16px horizontal correction
at frame3356, bank10 PC$A2ED. Standing turtle side samples span32px and can miss
an entire16px block between them. When the top sample finally enters the block,
the generic wall clamp makes a large correction. This was a gameplay failure,
not the temporary projectile-origin phenomenon previously guarded elsewhere.

The turtle adapter now samples the intervening row in the same actual terrain
column when an upper sample is empty. Rolling/lower/nonempty paths retain their
prior results. Row12 is bounded; no RAM is allocated. A private specialization
of the original player-side query removes only its generic mode stack and
object-index work, retaining pointer, row, nibble and arithmetic results.
11880 independent geometry cases pass;1008 previously missed thin cells are
now found. Existing-result registers/flags/RAM are exact outside discarded stack.

A fresh cold Hard Donatello component retains native first-screen floor and
arranges one logical floating solid and coherent native recoil. The unchanged
baseline makes a13px correction; PV's maximum observed step is3px. The logical
test cell is not drawn into the nametable, so its screenshots support actor
movement, not background-rendering fidelity.
