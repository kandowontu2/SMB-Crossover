## Proposed behavior

Only the native large-platform collision call is adapted. For selected raw40,
require nonnegative native vertical delta, native state0 or2 in its legal
0..3 domain, previous same-slot passenger, footer at least32 and a **nonwrapping
exact gap of2** to the platform ordinate. Save the real footer on the genuine
6502 stack, temporarily set it to that ordinate for the actual native LPC,
then restore it before returning. The original native collision routine still
tests horizontal overlap, offscreen/high-Y, actor state and timer; it still
admits or rejects the contact. The later existing position/carry callback still
enforces the original pre-snap fatal-fall threshold and source state.

This is a descending attachment correction. Negative native VY, unsupported
initial boarding, other gaps, vine/native1 states and foreign characters follow
the old collision behavior. It does not repair every upward platform case or
the independent original source one-way support issue. Enemy collision boxes,
terrain, original support windows, jump impulse, damage, actor size/position and
all original private fields are unchanged. No blanket enlarged player body.

Native integer VY is **not** used alone to infer original upward motion. The
previous-passenger condition is necessary. An ordinary three-branch source
witness starts from a single genuine downward944 carry, then presses A with
neutral/right/left controls, without changing game state or actors. Each first
source3 LPC has impulse352, acceleration8, fraction152, native VY255 and old
passenger3; the real LPC clears it to255. Each branch later reaches one still
rising integer-zero/nonnegative VY sample with passenger already255, so the
proposed conjunction never admits it. Across36 source3 LPC samples, none is
admitted. Receipt
`e99f295a4b53ef7f22d60ce5453220d47f1949db67cbeaec7092d6efb3ef4915`.
This is one real prefix and three input branches, not universal lifecycle proof.
The check deliberately permits a larger candidate set than the final footer
range restriction, so excluding every tested rising sample remains sufficient
for these branches. Its first draft mislabeled two unused diagnostic fields;
the frozen final receipt uses the actual C07F fraction/C082..83 acceleration
and C086..87 impulse. The earlier9b19 receipt is superseded for those labels.

Original transition D257/D291 resets jump age; E9AE initializes acceleration8
and fraction F0, against the original352 impulse. All directions share that
gravity before horizontal motion. Thus the first representable native movement
is−1; passenger is cleared before later fractional near-apex zero deltas. The
footer lower bound32 also excludes nativeY0/1 and wrapped off-bottom rectangles,
where the normal anchor publication could fail to represent the first−1 step.
These are the intended legal invariants to falsify in mounted fixtures, together
with head-bump/vine, actor reuse, cold/retire and timer boundaries. No universal
claim is substituted for those required tests.
