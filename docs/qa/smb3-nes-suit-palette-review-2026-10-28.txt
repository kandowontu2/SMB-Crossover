Read-only NES SMB3 suit-palette verification; no palette change warranted.

The shared Fire/Frog/Tanooki/Hammer colors between Mario and Luigi match the
original NES game. This comparison uses local USA PRG0 and USA PRG1 ROMs,
not SNES/All-Stars or remembered appearances. The surviving authenticated
PRG1 source/rebuilt payload also matches the original PRG1 ROM payload.

Original physical PRG bank8 has PowerUp_Palettes at A529 and executable
Level_SetPlayerPUpPal at A549 (83 bytes). Both USA revisions have identical
table and routine bytes at those addresses. The actual selector uses
Player_Current only for Small, Super and Raccoon; all other suits use their
own shared table row, with Statue using row7.

Actual three colors queued to PPU3F11:
Small/Super/Raccoon Mario:16,36,0F; Luigi:2A,36,0F.
Fire both:27,36,16. Frog both:2A,36,0F.
Tanooki both:17,36,0F. Hammer both:30,27,0F.
Tanooki Statue both:00,10,0F. (All values hexadecimal.)

Current src/smb3_mario_render.s M3Palette selects those same rows and
src/smb3_mario_art.inc M3NativePalettes contains the exact original triples,
compacting only each source row's unused first byte. The actual32 complete
original/current routine comparisons PASS: USA PRG0/PRG1 x two identities x
seven suits plus the Tanooki statue selector. These isolated CPU calls declare
form/player/statue and an empty queue; they are not earned-pickup campaigns.
Every queued7-byte command including
3F11 address/count/colors/terminator matches. This verifies palette dispatch
and data, not all pixels/animations or every regional NES revision.
