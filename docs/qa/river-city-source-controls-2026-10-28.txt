Implemented play, and deliberate crossover adaptations
Original native D5E7 movement produces 1.5px walk / 3.5px run. These speeds
and double-tap running are retained. The jump is deliberately adapted to
SMB terrain: -6.5px takeoff, .25px gravity and 7px fall cap, not a claim of
an exact original River City jump. Ordinary climbing/water integration
uses the existing host owners. Ground attacks stop walking during their
finite windup/contact/recovery; airborne kicks retain momentum.
Punch/kick damage, private enemy HP and stun, typed grab, carry and native
defeated-body throw are implemented. Only Goomba/green/red Koopa can be
grabbed; no boss/controller/Firebar is forced into ordinary movement.
Private stun never writes SMB Enemy_State. Releasing carry restores the
captured native velocities. Native defeat owns score/drops/defeat motion.
Actual free-standing pipes, chains, weapons, shops and original RPG menus
are not ported or claimed. Mushrooms/flowers are crossover healing/book
upgrades: +24HP up to64, strength tier up to2, repeated held-B attacks
after the first upgrade. No original shop-stat equivalence is claimed.
Easy delegates ordinary stomp eligibility; Hard relies on melee. Native
Star/1-Up remain host-owned. Per-variant HP/tier survive area changes and
earned life increases; a genuine one-life decrease resets the selected
variant. Death has finite animation/transition. No audio bank is added;
existing punch/impact cues are crossover cues, not original music/SFX.

Root-owned integration contracts
Named segments: CORE bank81 A300..BFFF; ART bank70 CB80..DB7F;
CHR716..723. Variant5FED, persistent5FA0..5FAF, scratch5C00..5C7F.
Root must admit only character21 before the identity-exclusive leaves.
Movement runs once per completed active update; Weapons follows movement.
RcEnemyControl(X actual slot) returns carry=1 when its typed movement is
consumed, carry=0 otherwise. RcBodyContact/RcPickup/RcInjuryStart likewise
report handled with carry; RcInjuryStatus returns A1 survive/protected,
A0 lethal. RcVisible returns carry=1 visible. RcCollisionAdder returns
carry=0 for standard host size/crouch; RcCollisionBox returns Y0/Y2.
RcGraphics selects the actual body record/bank; RcDraw publishes its CHR
windows. RcGraphicsBank selects physical C70. RcUi queues dirty HP/palette
only within the native84B buffer. RcStatusName preserves Y, returns A0,
and now writes exactly seven cells11..17, preserving next command byte18.
Other leaf calls have volatile A/X/Y/P with balanced stack; callers must
not infer register preservation absent an explicit contract above.
