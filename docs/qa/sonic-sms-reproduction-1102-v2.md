# Sonic Master System source reproduction

The user's supplied Sonic The Hedgehog (USA, Europe, Brazil) Master System ROM
has been rebuilt byte-for-byte from the original disassembly generated by
https://github.com/iamgreaser/s1smsdisasm-gm at revision
`91e9dd6f77393cd820efd5785229141b525f56b2`.

All 262,144 bytes match SHA256
`6ad738965ece231427ee046b9905cfee470d5c01220afdd934da4673e4a2458b`.
The original annotation/extractor pipeline and official WLA-DX10.7 Win64
assembler/linker were used; no modified diet source was substituted.

The bounded source/tool/output directory is
`build/sonic-sms-original-1102-v2`: 279 files, 4,018,745 bytes at qualification.
Only eight extractor Python files, the link recipe, two executable tools and
the previously pinned annotations were fetched. The source ROM was read from
the user's existing ZIP; no source/archive forest was cloned.

Receipt: `build/sonic-sms-original-1102-v2/reproduction.json`.
Generated assembly SHA256:
`03a9d7dba929deeb68a327dbbab2ef89d1bafc49437a1109a1fff97c7fe0e9f7`.

This proves original-source reproduction. NES instruction translation,
collision/rendering/audio integration, menu admission and gameplay tests remain
required. The Master System reference supersedes the earlier Sonic3 choice.

## First private 6502 primitive

`tools/audit/port_sonic_x_velocity_1102_v3.py` translates original bank1
`4B1B..4B49` (exclusive end): the horizontal velocity commit, sign-crossing
clamp and zero-velocity exception. The 65-byte assembled 6502 routine matches
an interpreter executing the original ROM opcodes in 9,928 boundary/random
cases. Live HL/C/B/DE, stored 24-bit velocity and final accumulator agree;
measured routine cost is 73–97 NES CPU cycles.

This is fixture-only code with no host RAM allocation or menu integration.
It does not yet cover acceleration selection, jumping, rolling, terrain,
rendering or a full caller-register contract. Receipt:
`build/sonic-sms-xvelocity-1102-v3/receipt.json`.
