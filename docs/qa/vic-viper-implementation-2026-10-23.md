# Vic Viper implementation

Playable on the expanded MMC5 target in third-row slot17, raw ID18. A fires; B buys the currently highlighted Gradius power-bar upgrade. The original six cells are Speed Up, Missile, Double, Laser, Option and Shield. Two Options are supported. Collecting physical capsules advances the cursor; owned/refused purchases retain the cursor, and Double/Laser replace each other. The source shield absorbs five contacts; the sixth is fatal. Solid terrain bypasses the shield.

Movement, clamps, fractional speed, tilt timing, Option history, firing slots/timers, missile flight/crawl and gun movement are retargeted original USA cartridge instructions. Original ROM SHA-256: `38c44e0e6f531a2779271f10cd4daa08ee2616c59c49d476b6f4e9dc482bf5f3`. Annotated primary reference is Fabulu/Mixup commit `314625258387309119e69e37aaf3365197235119`; numeric instructions and pixels were authenticated against the local ROM. Existing component receipts cover16,800 movement cases,18,144 purchases,3,584 capsule calls,4,320 weapon arenas and13,200 actual SMB terrain queries. The weapon arenas used explicitly declared test callbacks; they are not traversal evidence.

Original ship, Option, bullet, missile, capsule and explosion pixels are repacked into physical CHR380..393, with the native enemy half of each2KB pair retained. Page394 holds the original six power-bar cell masks, packed alongside all40 existing HUD glyphs. Body/weapon records occupy PRG76/C; original programs use75/A and the SMB adapters77/A. State owns ExRAM5D00..5DFF. No original SRAM allocation grows. The original collision ship point, source X+4/Y+8, is translated into the SMB scene below its32px HUD rather than using the large visible ship as its collision rectangle.

SMB adapters are explicit: one-pixel auto-scroll uses the native camera/parser until native ScrollLock; source screen movement remains independent of that scrolling. Mushroom/flower blocks produce visibly emerging capsules, and every third eligible defeated enemy drops a private capsule without taking an enemy/platform slot. Actual contact grants it. Native strict projectile block transactions preserve the player's position. Coins, flagpoles, axes, paired Down-entry warp pipes and sideways exit pipes use native world transactions/scripts. Life loss resets Gradius equipment; pipe/area transitions preserve it.

The larger HUD requires separate font publication. All four native area's first1KB font pages deduplicate to physical0. The expanded IRQ restores that page early, while replacing six cycles of its native delay with six cycles of font publication.512 linked CPU cases prove identical final PPU scroll values and write cycles, interrupted registers/flags and stack. Native full-ensemble tests verify the world font is restored before the first world pattern fetch. The ordinary mapper targets remain byte-identical.

Root verified13 combined native scenes: ordinary ship selection/flight/fire/auto-scroll; authored actual capsule contact and all six upgrade choices; source missiles, Double, Laser, two Options and shield/death/new-life; visible question-block emergence and collection; shot SFX routing; coins and all exit types; terrain/shield policy. Turtle, Chip/Dale, Kirby, Darkwing, Zelda II Link and Proto Man regression scenes pass in the same binary. These are bounded controller scenes and explicitly authored arenas, with no campaign or video certification.

Current limitations: music inherits the existing Pit family and action effects use the existing SMB sound engine. Original Gradius audio remains pending. Original exhaust06 maps to26, and bullet21 maps to2C; white uses an existing native world palette through layered sprites. The power bar collapses source frame/letter colors into the native HUD foreground, preserving their masks. These palette-sharing choices can increase sprite overlap; the existing rotating OAM admission applies. Capsule delivery and SMB world/exit rules are adaptations rather than claims that Gradius originally contained Mario levels. Full campaigns, cartridge testing and the remaining roster are unfinished.
