SMALLEST SHARED IMPLEMENTATION / STORAGE CONSTRAINT

Use one common identity/event dispatcher and existing owner-aware guest mixer,
source-bank read helpers, restart/pause lifecycle and persistent DMC mechanism;
retain two actual original cores. Route17 to SMB3; route18 variants1..3 to one
Parodius core with its real hero request; preserve variant0 Gradius. Prove every
new boundary's register/stack/IRQ and source APU/state outcomes. This avoids five
copies and avoids replaying pre-truncated register recordings as invented music.

contains live CV3 samples/manager and reserved TMNT cold adapter; it cannot be
blindly overwritten by Parodius's proposed$F140..$F640 mirror. The former A62/C94
Parodius placement is obsolete: ROOT reserves those tails for Chip's authentic
music. Held TMNT's source-qualified124-to99 exchange is not installed by2cb5;
bank124 is not released. Mac123, Mike115, fixed127 and existing reachable songs,
code and CHR remain preserved. No unreserved whole8KiB bank was established.

then a single source-declared fragmented data/read-helper and DMC-mirror layout
for both cores, based on current map plus explicit held-family reservations.

architecture with full old-owner/preemption/tail proofs; do not drop drums,
truncate songs, assume held-bank exchanges, or silently use Pit. Bank/RAM
allocation and music installation are deliberately not performed here.
