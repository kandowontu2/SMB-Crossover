## Five native bytes, existing storage

five bytes are PHP / PLP / JMP A7EB; the existing immutable A7EB leaf loads
SafecallA and returns CLC. PHP/PLP reproduces the old generic transport's
model status-bit5 normalization, including artificial inputs with that bit
clear. The bare A7EB shortcut failed that direct test and is not proposed.

The UI-only change preserves every source component, cookie, original actor,
