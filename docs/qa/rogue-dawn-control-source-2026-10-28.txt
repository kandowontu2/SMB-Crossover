Actual source draw-context dependency
Native D0CD is LDA CCC0,X without a preceding TAX. X is the original8x8 draw
return cursor, not facing and not the host8x16 OAM cursor. Actual Main CB29
resets native5B, draws enemies F345, then three projectile owners D4BF, then
player CC0D. Prior source-compatible emissions therefore contribute.
For body frame8 with no prior draws the native returnX is36; after an actual
beam it is64; after missile+beam92; after three projectiles120. F7 emits no
body, preserves5B, but returnsX0. Do not simplify this output to constant36.
The literal256B CCC0..CDBF source window is adapter data, not executable host
room logic. ROOT must derive contextual original-format draw metadata or
explicitly qualify a separate intentional adaptation. A mocked/fixed draw
cursor is not a full native movement campaign.
